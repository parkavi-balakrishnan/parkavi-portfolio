# Parkavi Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or run:
   `python3 -m http.server 5500`
3. Visit `http://localhost:5500`

## Customize before publishing
- Replace `your-email@example.com` in `index.html`.
- Add your real GitHub/LinkedIn/Instagram URLs.
- Replace the `#` project links with your repositories/live demos.
- Add a profile photo if you want one.
